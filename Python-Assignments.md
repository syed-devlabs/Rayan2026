# Python-Assignments 


#1 Create a game where the player plays Rock, Paper, Scissors against the computer.

Requirements
The program should: Ask the player to choose:
rock
paper
scissors
Computer randomly chooses one.
Display both choices.
Decide who wins.
Keep score.

Example:

🎮 ROCK PAPER SCISSORS

Choose rock, paper, or scissors: rock

You chose: rock
Computer chose: scissors

🎉 You win!

Your score: 1
Computer score: 0

Play again? yes
Rules
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
🧩 Skills Required

The child should try to use:

import random
input()
print()
if / elif / else
while
variables
